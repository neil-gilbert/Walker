Imagine a purchase rule changes from balance >= price to balance > price. If every test still passes, nobody checked the exact-balance boundary.

Walker makes deliberate behavioural changes like this, runs your tests, and reports the mutations that survive. You investigate the missing assertion, equivalent behaviour or production defect.

Walker.Cli on NuGet ↗

Install the current preview as a global .NET tool:

TERMINAL / GLOBAL INSTALL 
dotnet tool install --global Walker.Cli --prerelease

Bring: the .NET 10 SDK, Git, and the SDKs and test runtimes required by your target repository. Package checks run on Linux, macOS and Windows, against .NET 8 and .NET 10 test projects.

Run from your target Git repository

TERMINAL / VERIFY THE DIFF 
walker verify --isolate --base HEAD~1 \
  --project src/Payments/Payments.csproj \
  --tests tests/Payments.Tests/Payments.Tests.csproj \
  --timeout 60 --max-mutants 20 --format json

Replace the project paths with yours and choose the Git base you want to check. --isolate verifies a captured private worktree and preserves your checkout.

Using Walker with a team or in CI?

Install a repository-local tool and commit the generated manifest. It records the resolved version so everyone restores the same tool. 

dotnet new tool-manifest # skip if the repository already has one
dotnet tool install Walker.Cli --prerelease
# Commit .config/dotnet-tools.json; on subsequent checkouts:
dotnet tool restore
dotnet tool run walker -- verify --help

Before you open the gate.

Is Walker a code coverage tool?

No. Coverage measures which code is executed. Walker tests whether deliberate behavioural changes are detected. It focuses on your Git diff, rather than producing a whole-repository mutation score.

Does my application need to target .NET 10?

Walker itself requires the .NET 10 SDK. Your target repository uses its own SDKs and test runtimes. The distributed tool is checked against .NET 8 and .NET 10 test projects.

Is it free and open source?

Yes. Walker is distributed under the MIT licence. This is a preview release; review the release notes before upgrading.

How do I update or remove it? 
dotnet tool update --global Walker.Cli --prerelease
dotnet tool uninstall --global Walker.Cli

For a repository-local tool, omit --global. Commit the updated manifest after upgrading.
